# 🏦 Bankist - Advanced DOM Manipulation Website

An interactive banking landing page built using **HTML5, CSS3, and Vanilla JavaScript** that demonstrates advanced DOM manipulation techniques and modern JavaScript concepts.

---

## 🚀 Live Features

- ✅ Modal Window
- ✅ Smooth Scrolling Navigation
- ✅ Sticky Navigation Bar
- ✅ Tabbed Component
- ✅ Navigation Fade Animation
- ✅ Reveal Sections on Scroll
- ✅ Lazy Loading Images
- ✅ Interactive Image Slider
- ✅ Keyboard Navigation
- ✅ Dynamic Dot Navigation
- ✅ Event Delegation
- ✅ Intersection Observer API
- ✅ Fully Responsive UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)

---

- DOM Manipulation
